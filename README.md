# AutoMinds Africa — Smart Digital Profile

Premium, mobile-first Smart Digital Profile for AutoMinds Africa.

## Production goals
- Fast NFC / QR opening experience
- Premium animated loader without slowing repeat visits
- Verified core contact routes
- Clear AutoMinds Africa service positioning
- Save-contact (.vcf) support
- Native share + clipboard fallback
- Responsive, accessible, static-hosting friendly
